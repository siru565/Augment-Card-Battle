> Godot 4.7 (.NET / C#) · Steam P2P 멀티 · itch.io 배포

## 1. 기반 만들기 — "규칙은 한 곳에서만"

- **Core / UI / Net 분리**: 게임 규칙(`GameEngine`)은 Godot에 전혀 의존하지 않게 만들었다. 덕분에 같은 코드를 콘솔 테스트, 봇 시뮬레이션, 멀티 서버에서 그대로 쓴다.
- **상태 변경은 `Apply(player, action)` 하나로만**: 잘못된 행동은 상태를 건드리지 않고 실패만 돌려준다.
- **PlayerView**: 플레이어마다 "봐도 되는 정보"만 담은 뷰를 만든다. 남의 손패는 장수만 보인다. 봇도 이 뷰만 보고 판단해서 치팅이 불가능하다.
- **테스트용 봇 2종**: 아무거나 내는 랜덤봇, 우선순위로 판단하는 규칙봇. 봇끼리 수천 판을 돌려 버그와 밸런스를 잡았다.

## 2. 우노에서 벗어나기

- 카드 디자인을 우노와 완전히 다르게 바꿨다: 색 대신 **불꽃·달빛·숲·물결** 4문양 + **프리즘**. 이미지 없이 전부 벡터로 그린다(마름모 문장, 문양 아이콘, 뒷면 격자).
- 특수 카드 추가: **교환**(카드 1장 맞바꾸기), **봉인**(숫자만 내게), **복사**(직전 효과 재발동), **폭주**(같은 문양 숫자 연속 내기).
- 카드에 마우스를 올리면 **설명 팝업**이 뜬다.

## 3. 각성 카드 — 롤 증강처럼 3개 중 1개

각성 카드를 내면 능력 3개가 나오고 하나를 골라 즉시 발동한다.

| 능력 | 효과 |
|---|---|
| 심연의 부름 | 다음 사람이 지금 문양이 나올 때까지 계속 뽑기 (최대 25장) |
| 대회전 | 모든 손패를 다음 자리로 통째로 넘기기 |
| 운명 교환 | 한 명과 손패 통째로 바꾸기 |
| 저주의 낙인 | 지정한 사람이 지정한 문양이 나올 때까지 계속 뽑기 |
| 균형의 저울 | 모두의 손패를 모아 똑같이 나누기 |
| 그 외 | 카드 폭풍, 문양 숙청, 시간 정지, 대봉인, 선물 상자 |

## 4. 멀티플레이 — 포트포워딩 없이

- 처음엔 ENet(IP 직접 연결)으로 만들고, 이후 **Steam 네트워크(SDR 중계)** 를 붙여서 포트포워딩 없이 방 코드만으로 들어올 수 있게 했다.
- 구조는 **서버 권한(Host authoritative)**: 방장만 규칙을 판정하고, 참가자는 행동만 보내고 자기 시점의 뷰만 받는다.
- 한 프로세스에 방장 화면과 참가자 화면을 띄워 실제 ENet으로 한 판을 자동으로 끝까지 두는 **네트워크 자동 테스트**를 만들었다.

## 5. 배포 자동화 — itch.io

- `publish_itch.bat` 하나로 **버전 올리기 → Windows 내보내기 → butler 업로드**까지 자동으로 한다.
- itch 앱으로 설치한 친구들은 **자동으로 업데이트**된다. 멀티는 버전이 다르면 접속을 막아서 규칙이 꼬이지 않게 했다.
- 삽질: 내보내기가 10분씩 멈추는 문제 → MSBuild 노드 재사용이 파이프를 붙잡고 있던 것. 환경 변수로 끄고 해결.

## 6. v0.1.4 — 특수 증강 시스템

기존의 "뽑으면 나오는 랜덤 증강"을 없애고, **게임 규칙 자체를 바꾸는 특수 증강**으로 갈아엎었다.

- **어벤져스**: 내 카드가 전사·궁수·해적·도적·마법사·어부·낚시꾼·농부 직업 카드가 되고, 8직업을 모으면 승리
- **블랙홀**: 손패를 모으면 오히려 승리 / **수집가**: 같은 숫자를 네 문양 모두 모으면 승리
- 평화주의자, 광전사, 연금술사, 문양 군주, 시간술사 등
- **카드를 직접 뽑게**: +2·+4를 맞으면 시스템이 알아서 뽑아 주는 대신, 당한 사람이 **직접 덱을 눌러 한 장씩** 뽑는다. 손맛이 확 산다.
- **연출**: 각성 때 화면 번쩍임 + 빛줄기 + 지진, 공격 때 붉은 번쩍임과 흔들림, 카드가 날아가는 애니메이션, 승리 때 색종이
- **대기방**: 게임이 끝나도 방 코드가 유지되고, 방장 강퇴·설정, 게임 안에서 Steam 친구에게 바로 초대

## 7. v0.1.5 — 소리와 편의

- 게임 중 나가기 → 대기방으로. 나간 자리는 **봇이 이어받는다**.
- 메인 화면 전용 배경 (떠다니는 카드, 빛 알갱이, 도는 빛줄기)
- **효과음 20종을 코드로 합성** (사인파·잡음·필터·메아리). 나중에 산 에셋을 같은 이름으로 넣으면 자동으로 교체되게 만들었다.
- **설정 창**: 화면 모드·해상도, 전체/효과음/배경음악 볼륨
- 배경음악: "Backbay Lounge" (Kevin MacLeod, CC BY 4.0)

## 8. v0.1.6 ~ v0.1.7 — 합산 규칙과 증강 확장

- **+카드 합산**: 공격을 받으면 바로 먹지 않고 +카드를 얹어서 다음 사람에게 넘긴다. 못 넘기면 합계를 한 번에 받는다.
- **+1 / +2 / +3 / +4**: 같은 + 숫자끼리는 문양 상관없이 합산, 프리즘 +4는 어떤 +카드와도 합산
- 시작할 때 **모두 동시에** 첫 증강을 고르게 바꿔서 시작 대기 시간을 없앴다.
- **어벤져스 난이도 상향**: 숫자 카드에만 직업이 붙고, 8직업을 모은 채로 **한 바퀴를 버텨야** 승리. 모으는 순간 모두에게 들킨다.
- 새 증강: 반사의 거울, 쌍둥이, 시간 도둑, 저격수, 불사조, 도박사, 폭탄마

## 9. v0.1.8 ~ v0.1.9 — 순위전

- **끝까지 순위 가리기**: 1등이 나와도 남은 사람끼리 계속해서 2·3·4등을 정한다. 마지막 카드의 효과도 그대로 발동한다.
- **탈락**: 손패가 30장이 되면 탈락하고 꼴찌가 된다. (블랙홀은 예외)
- 사람이 모두 빠지면 남은 봇들의 판을 4배 빠르게 진행하고, 끝나면 최종 순위표를 보여 준다.
- **도박사**: 2장을 펼쳐 놓고 직접 한 장을 고르는 선택 창 추가 (원래는 자동 선택이라 버그처럼 보였다)
- 증강 24종으로 확장: 실버 12 > 골드 8 > 프리즘 4
  - 새 증강: 행운의 7, 청소부, 수호천사, 역풍, 자유로운 영혼, 짝수 애호가, 선견지명, 지배자

## 밸런스 이렇게 잡았다

새 증강을 넣을 때마다 **규칙봇 4명 × 4,000판**을 돌려서 "그 증강을 가진 사람의 1등 확률"을 쟀다. 4인 게임이라 목표는 **25% 근처**.

| 문제 | 측정값 | 조정 |
|---|---|---|
| 평화주의자가 너무 약함 | 11.7% | +2·+4를 못 내서 손에 갇힘 → 낼 수는 있지만 효과가 사라지게 변경 → 26% |
| 블랙홀이 너무 강함 | 39% | 목표 장수 20 → 22 → 25 → 28장 |
| 문양 군주가 강함 | 32% | 모든 카드 → 숫자 카드만 언제든 낼 수 있게 |
| 어벤져스가 너무 쉬움 | 직업 승리 4.3% | 숫자 카드만 + 한 바퀴 버티기 → 1.0% |

현재 24종 모두 1등 확률 **18~30%** 안에 있다.

## 배운 점

- **규칙을 UI와 분리**해 두니 봇 시뮬레이션·네트워크·테스트를 전부 같은 코드로 할 수 있었다. 밸런스를 "감"이 아니라 숫자로 볼 수 있었던 게 가장 컸다.
- **"시스템이 알아서"보다 "플레이어가 직접"** 이 손맛을 만든다. 공격 카드를 직접 뽑게 바꾼 게 체감상 가장 큰 변화였다.
- 멀티는 처음부터 **서버 권한 + 플레이어별 뷰**로 설계해서, 나중에 대기방·중간 퇴장·봇 대체를 붙일 때 구조를 거의 바꾸지 않아도 됐다.
