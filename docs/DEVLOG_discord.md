───── 메시지 1 ─────

이번에는 우노 규칙 위에 판의 규칙 자체를 바꾸는 증강을 얹은 멀티플레이 카드게임 "증강 카드 배틀"을 만들어 보았습니다.
엔진은 Godot 4.7 .NET 버전을 쓰고 언어는 C#으로 작성했습니다.

첫번째로 게임 전체의 뼈대를 잡았습니다.
카드게임은 나중에 멀티로 갈 거라서 처음부터 규칙 코드와 화면 코드를 완전히 분리했습니다. 게임 규칙을 담당하는 GameEngine은 Godot 코드를 하나도 쓰지 않는 순수 C# 클래스로 만들어서, 같은 코드를 콘솔 테스트, 봇 시뮬레이션, 멀티 서버에서 그대로 쓸 수 있게 했습니다.

게임 상태를 바꾸는 방법은 Apply(플레이어, 행동) 함수 하나뿐이고, 규칙에 안 맞는 행동이 들어오면 상태를 건드리지 않고 실패만 돌려주게 했습니다. 이렇게 입구를 하나로 막아두니 버그가 생겨도 어디서 생겼는지 찾기가 편했습니다.

그리고 플레이어마다 볼 수 있는 정보만 담은 PlayerView를 따로 만들었습니다. 남의 손패는 장수만 들어가고 카드 내용은 안 들어갑니다. 봇도 이 PlayerView만 보고 판단하게 해서 봇이 남의 패를 훔쳐보는 일이 구조적으로 불가능하게 만들었습니다.

카드는 우노랑 겹치지 않게 불꽃·달빛·숲·물결 4문양 + 프리즘으로 바꾸고, 이미지 파일 없이 전부 _Draw로 벡터를 직접 그려서 만들었습니다.

───── 메시지 2 ─────

두번째로 멀티플레이 구조를 만들었습니다.
구조는 서버 권한(Host authoritative) 방식으로 방장 컴퓨터의 GameEngine만 규칙을 판정하고, 참가자는 "이 카드를 낸다" 같은 행동만 보내고 자기 시점의 PlayerView만 받도록 했습니다. 참가자 쪽에서 판정을 안 하니깐 조작해도 규칙을 어길 수가 없습니다.

메시지는 JSON 한 줄로 주고받고, 전송 계층은 IServerTransport / IClientTransport 인터페이스로 추상화했습니다. 처음에는 Godot의 ENet(MultiplayerAPI의 RPC)으로 IP 직접 연결을 만들었는데, RPC는 모든 피어에서 노드 경로가 같아야 해서 /root/Game/Net 경로에 문자열만 옮기는 NetBridge 노드를 두는 방식으로 해결했습니다.

멀티 테스트를 매번 창 두 개 띄워서 하기 힘들어서, 한 프로세스 안에 SubViewport 두 개를 만들고 각각 SetMultiplayer로 따로 MultiplayerAPI를 붙여서 방장 화면과 참가자 화면이 실제 ENet으로 접속해 봇 두뇌로 한 판을 끝까지 두는 자동 테스트를 만들었습니다. 왼쪽이 방장, 오른쪽이 참가자 화면입니다.

───── 메시지 3 ─────

세번째로 포트포워딩 없이 친구랑 바로 할 수 있게 Steam 네트워크를 붙였습니다.
Steamworks.NET을 쓰고 SteamNetworkingSockets의 P2P 연결을 사용했습니다. 이 연결은 Steam 중계망(SDR)을 거쳐서 가기 때문에 공유기 설정 없이도 연결이 됩니다.

방은 Steam 로비로 만들고, 64비트짜리 로비 ID를 친구에게 불러주기 쉽게 36진수로 바꿔서 "방 코드"로 보여주게 했습니다. 참가자는 코드로 로비에 들어간 다음 로비 주인의 Steam ID로 P2P 연결을 겁니다. 앞에서 전송 계층을 인터페이스로 나눠둔 덕분에 Steam 전송 클래스만 새로 만들고 게임 코드는 하나도 안 고쳐도 됐습니다.

만들다 보니 Godot C#에서 steam_api64.dll을 못 찾는 문제가 있었는데, NativeLibrary.SetDllImportResolver로 프로젝트 폴더, 빌드 폴더, 내보낸 exe 폴더를 직접 뒤져서 불러오게 해서 해결했습니다.

Steam 초대가 안 되는 문제도 있었는데, itch로 받은 게임은 Steam으로 실행한 게 아니라서 오버레이가 안 붙고, 테스트용 앱 ID 480은 초대를 수락하면 Spacewar를 실행하려고 해서 생기는 문제였습니다. 그래서 오버레이 대신 게임 안에 친구 목록을 띄워서 InviteUserToLobby로 직접 초대하고, 받는 쪽은 LobbyInvite_t 콜백으로 게임 안에 참가 알림을 띄우게 만들었습니다.

───── 메시지 4 ─────

네번째로 대기방을 만들었습니다.
게임이 끝나도 Steam 로비를 닫지 않고 유지해서 방 코드가 바뀌지 않게 했고, 자리마다 Local / Remote / Bot 종류를 두어서 빈자리는 봇이 채우게 했습니다.

게임 도중에 누가 나가거나 연결이 끊기면 그 자리 종류만 Bot으로 바꿔서 손패 그대로 봇이 이어서 플레이하게 했습니다. 사람이 전부 빠지면 남은 봇들의 판은 4배 빠르게 돌리도록 했습니다.

강퇴는 연결을 바로 끊으면 "강퇴당했습니다" 메시지가 도착하기 전에 끊겨버려서, 메시지를 먼저 보내고 0.6초 뒤에 연결을 끊게 했습니다. 강퇴한 사람은 Steam ID를 기억해 두었다가 다시 못 들어오게 막았습니다.

또 버전이 다르면 규칙이 달라서 게임이 꼬이기 때문에 접속할 때 버전을 먼저 보내서 방장과 다르면 업데이트하라는 안내를 띄우고 돌려보내게 했습니다.

───── 메시지 5 ─────

다섯번째로 게임의 핵심인 특수 증강을 만들었습니다.
롤 증강처럼 게임 시작할 때 3개 중 하나를 고르고, 6번째 차례에 하나를 더 고르는 방식입니다. 처음에는 각자 자기 첫 차례에 고르게 했더니 뒷자리 사람은 앞사람들이 고르고 카드 내는 걸 다 기다려야 해서 6초 가까이 멈춰 있었습니다. 그래서 시작할 때 모두가 동시에 고르게 바꾸고, 봇들은 0.4초 뒤에 한꺼번에 고르게 해서 대기 시간을 없앴습니다.

증강은 단순히 수치를 올려주는 게 아니라 규칙 자체를 바꾸는 쪽으로 만들었습니다. 예를 들어 "블랙홀"은 손패를 28장 모으면 승리, "어벤져스"는 숫자 카드가 직업 카드가 돼서 8직업을 모으면 승리처럼 승리 조건이 바뀝니다. 지금은 실버 12, 골드 8, 프리즘 4개로 총 24종이 있습니다.

증강 중에 "도박사"는 카드를 뽑을 때 2장을 보고 하나를 고르는 증강인데, 처음에는 엔진이 낼 수 있는 카드를 자동으로 골라주게 만들어서 플레이어 입장에선 효과가 안 보이는 버그처럼 느껴졌습니다.

───── 메시지 7 ─────

여섯번째로 게임의 손맛을 살리는 작업을 했습니다.
원래는 +2, +4를 맞으면 시스템이 알아서 카드를 넣어줬는데 이게 너무 밋밋해서 당한 사람이 직접 덱을 눌러서 한 장씩 뽑게 바꿨습니다.

그리고 +카드 합산 규칙을 넣었습니다. 공격을 받으면 바로 뽑는 게 아니라 PendingPenalty에 누적시켜두고, 받은 사람은 같은 +숫자 카드(+1은 +1, +3은 +3, 문양 상관없음)나 프리즘 +4를 얹어서 다음 사람한테 넘기거나, 못 넘기면 합계를 한 번에 받게 했습니다. 공격이 넘어오면 화면이 붉게 번쩍이고 흔들리면서 누적 장수가 크게 뜹니다.

일곱번째로 효과음을 직접 만들어 보았습니다.

사인파, 삼각파 같은 기본 파형에 음높이를 지수적으로 미끄러뜨리고, 잡음(노이즈)에는 차단 주파수가 움직이는 1차 로우패스 필터를 걸어서 "휙", "쾅" 같은 느낌을 냈습니다. 여기에 메아리를 더하고 16비트 PCM으로 바꿔서 Godot의 AudioStreamWav에 바로 넣었습니다. 이렇게 카드 내기, 공격, 각성, 승리 팡파르 등 20종을 만들었습니다.

───── 메시지 12 ─────

마지막으로 밸런스는 감이 아니라 숫자로 맞춰보았습니다.
특수 증강을 넣을 때마다 규칙봇 4명으로 4,000판을 자동으로 돌려서 "그 증강을 가진 사람이 1등할 확률"을 쟀습니다. 4인 게임이라 목표는 25% 근처로 잡았습니다.

해보니깐 평화주의자는 11.7%로 너무 약했는데, 원인을 보니 +2, +4를 못 내게 막아놔서 그 카드가 손에 갇혀버리는 문제였습니다. 그래서 낼 수는 있지만 효과만 없어지게 바꿨더니 26%로 올라왔습니다. 반대로 블랙홀은 39%로 너무 강해서 목표 장수를 20장에서 28장까지 올렸습니다. 지금은 증강 24종 모두 1등 확률이 18~30% 안에 들어와 있습니다.

배포는 itch.io의 butler를 써서 배치 파일 하나로 버전 올리기 → Windows 내보내기 → 업로드까지 자동으로 되게 했고, itch 앱으로 받은 사람은 자동으로 업데이트됩니다. 처음에 내보내기가 10분씩 멈췄는데 MSBuild가 빌드 노드를 재사용하면서 파이프를 붙잡고 있어서 생긴 문제라 MSBUILDDISABLENODEREUSE 환경 변수로 꺼서 해결했습니다.
