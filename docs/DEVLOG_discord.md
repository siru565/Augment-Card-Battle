# 🃏 증강 카드 배틀 개발일지 #1
우노 규칙 위에 **판의 규칙을 바꾸는 "특수 증강"** 을 얹은 멀티플레이 카드 게임입니다.
`Godot 4.7 (C#)` · `Steam P2P 멀티` · `itch.io 자동 업데이트` · 현재 **v0.1.9**

**📦 지금까지 만든 것**
• 카드 140장 — 4문양(불꽃·달빛·숲·물결) + 프리즘, +1/+2/+3/+4, 교환·봉인·복사·폭주, 각성 카드
• **각성 카드**: 내면 능력 3개 중 하나를 골라 즉시 발동 (손패 통째로 바꾸기, 모두의 손패 돌리기 등 10종)
• **특수 증강 24종** (실버 12 · 골드 8 · 프리즘 4) — 시작할 때 모두 동시에 1개, 6번째 차례에 1개 더
• **다른 승리 조건**: 어벤져스(직업 8종 모으기), 블랙홀(손패 28장), 수집가(같은 숫자 4문양)
• **+카드 합산**: 같은 + 숫자끼리는 문양 상관없이 얹어서 넘기기, 프리즘 +4는 뭐든 합산
• **직접 뽑기**: 공격 맞으면 자동으로 안 뽑히고 내가 한 장씩 직접 뽑음 (손맛!)
• **순위전**: 1등 나와도 끝까지 2·3·4등을 가림, 손패 30장이면 탈락

**🌐 멀티 & 편의**
• Steam 로비로 포트포워딩 없이 방 코드만으로 접속, 게임 안에서 친구 초대
• 게임 끝나도 유지되는 대기방, 방장 강퇴·설정
• 중간에 나가면 봇이 자리를 이어받음
• 효과음 20종을 코드로 직접 합성 + 배경음악, 설정 창(해상도·볼륨)
• 화면 흔들림·번쩍임·빛줄기·파티클 연출

**🛠 기술적으로 신경 쓴 것**
• 게임 규칙(Core)을 Godot과 완전히 분리 → 같은 코드로 봇 시뮬레이션·멀티 서버·테스트
• 서버 권한 구조: 방장만 판정, 참가자는 자기 시점 정보만 받음 (남의 손패는 장수만)
• `publish_itch.bat` 하나로 버전 올리기 → 빌드 → 업로드까지 자동
